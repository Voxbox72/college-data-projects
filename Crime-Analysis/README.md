# Crime Analysis

Clustering analysis of San Francisco crime data using K-Means and K-Medoids to identify crime hotspots and patterns.

## Date
Completed: May 2023

## Dataset
The dataset is the San Francisco Crime Classification dataset from Kaggle.
Source: https://www.kaggle.com/competitions/sf-crime/data

1. Download the dataset from Kaggle.
2. Place 	rain.csv in this directory.

## Files
- Crime_rates.py - K-Means clustering and visualization
- Crime_rates_Kmedoids.py - K-Medoids clustering
- .gitignore - Excludes the local dataset

## Requirements
- Python 3, pandas, scikit-learn, matplotlib

## How to Run
`ash
pip install pandas scikit-learn matplotlib
python Crime_rates.py
