# College Data Projects

Collection of smaller data analysis and ML projects from college coursework.

## Projects
- [Insurance Regression](./InsuranceRegression) - Linear regression analysis on insurance charges to predict costs based on factors like age, BMI, and smoking status (R).
- [Crime Analysis](./Crime-Analysis) - Clustering analysis of crime data using K-Means and K-Medoids to identify crime patterns (Python).
- [Data Project](./DataProject) - Exploratory data analysis on Walmart sales data to uncover trends and insights (Python).
- [Sentiment Analysis](./Sentiment_analysis) - Text sentiment classification/analsis implementation (Python).
